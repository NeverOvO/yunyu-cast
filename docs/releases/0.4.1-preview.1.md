# 云屿投屏 0.4.1-preview.1

本版修复首页应用名称和手机连接引导在深蓝背景上显示为黑色的问题，两处文字现明确使用白色。同时修正两张图片的资源文件名。

## 安装

下载附件 `云屿投屏-0.4.1-preview.1.apk`，在 Android 8.0 及以上的 ARM32 / ARM64 电视安装。APK 使用原发布证书签名，可覆盖安装 0.2.0、0.3.0、0.4.0 并保留设置。0.1.0 调试签名版本或自行构建的调试包需要先卸载。

打开应用后自动接收。iPhone 使用“控制中心 → 屏幕镜像 → 云屿投屏”；支持 DLNA 或 AirPlay 的视频 App 可通过“TV / 投屏”按钮选择设备。手机和电视需要位于同一局域网。

遥控器返回会结束本次投屏并退出界面，接收服务继续运行。退出后再次投屏自动显示画面，需要电视允许应用显示在其他应用上层。

## 本版范围

- 版本名称：`0.4.1-preview.1`。
- versionCode：`5`。
- 应用包名：`com.yunyulai.tvcast`。
- 保留手绘云朵电视素材、自动接收、AirPlay / DLNA，以及 1080p / 2K / 4K、30 / 60 帧选项。

本版已完成 Release 构建和签名，没有重新运行测试、Lint 或电视真机复测。此前 0.4.0 的 13 项纯逻辑回归测试及发布前检查已通过，范围见仓库[审计记录](https://github.com/NeverOvO/yunyu-cast/blob/v0.4.1-preview.1/docs/audit-20261025.md)。

## 使用限制

不支持 DRM 受保护影片、Miracast、Google Cast 或视频平台自有接收协议。部分 App 的鉴权、设备白名单或媒体格式会限制发现和播放；本项目没有持续原生 4K60 的实机测试结论。

应用代码按 GPL v3 发布，基于 jqssun/android-airplay-server v0.0.36 与 UxPlay。对应源码、构建说明和许可材料位于本版本标签；安装与问题反馈见[项目 README](https://github.com/NeverOvO/yunyu-cast/tree/v0.4.1-preview.1)。
