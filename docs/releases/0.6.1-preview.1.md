# 云屿投屏 0.6.1-preview.1 发布说明

首页增加当前应用版本，更新与首次权限弹窗限制在窗口安全范围内，长内容可用遥控器滚动。镜像全屏、音乐快进快退和 PIN 显示补齐遥控及会话切换处理。

本版 versionCode 为 12，包名保持 `com.yunyulai.tvcast`，支持 Android 8.0 及以上的 ARM32 / ARM64 设备。Release 构建、16 KiB 对齐及原发布证书签名已完成。0.5.0 至 0.6.0 可从应用内“检查更新”获取本版，更早版本通过 U 盘或 ADB 手动覆盖安装。

[下载 APK](https://github.com/NeverOvO/yunyu-cast/releases/download/v0.6.1-preview.1/yunyu-cast-0.6.1-preview.1.apk) · [发布入口与完整附件](https://github.com/NeverOvO/yunyu-cast/releases/tag/v0.6.1-preview.1)

## 操作变化

- 首页右下角从系统包信息读取版本号。低高度和大字号布局为新增版本行保留空间，可用空间不足时使用页面滚动。
- 更新和首次权限弹窗以宿主窗口安全高度为上限。正文独立滚动，底部操作按钮保持可达。
- 镜像全屏控件隐藏后，方向键或确定键可以唤醒。唤醒按键不会顺带触发按钮，点击“退出全屏”回到应用内预览；实体返回键继续结束当前会话并退出界面。
- 音乐快进、快退按钮支持遥控按住操作，松开、失焦或控件销毁时结束。手势协程取消时清理拖动和缩放状态。
- 后台收到的 PIN 在绑定服务后恢复显示，直接视频播放期间也能显示配对弹窗。返回或确认只关闭 PIN 弹窗，画中画期间保留状态至返回应用。

## 接收与播放处理

DMAP 元数据限制为 1 MiB 和 32 层嵌套，共享缓冲替代逐层复制，整数只接受规定的字节宽度。封面在解码前检查 8 MiB 输入边界，按尺寸降采样并向 Media3 提供 PNG 缩略图。JNI 在向 JVM 复制这些数据之前执行相同的大小限制。

RAOP 音频进度处理 32 位时间戳回绕；暂停前记录当前播放位置。JNI 独立传递 `playWhenReady`，原生端可以区分缓冲和用户暂停。

MediaCodec 运行中致命错误交由生产线程按 1 秒退避重建。Oboe 设备断开或启动失败后，由后续音频包驱动恢复，按 1 秒间隔限制重试；暂停、停止后不自行重启，旧音频流回调不改变新流。音频环形存储使用 2 的幂次物理容量与掩码索引，处理 ARM32 长时运行中的计数器回绕，逻辑容量保持原值。

UxPlay 新增 0014、0015 补丁：检查 SETUP 加密字段长度，调整 HTTP 首包异步收发及分片解析，并限制请求资源。安装包准备使用进程内共享互斥锁，避免多个更新模型实例同时清理或写入同一临时文件。

## 构建与源码

当前 UxPlay 持久补丁为 0001 至 0015。Gradle 9.8.1 分发包和 OpenSSL 3.4.4 原始包固定 SHA-256；第三方组件版本和许可保持不变。

完整源码附件 `yunyu-cast-0.6.1-preview.1-source.tar.gz` 包含项目源码、四个固定提交的子模块源码、0001 至 0015 补丁、构建脚本和 OpenSSL 3.4.4 原始源码包。Release 同时提供 `SHA256SUMS.txt` 与 `THIRD_PARTY_NOTICES.md`；签名私钥和本机配置不随附件分发。旧 0.6.0 完整源码包仍只包含 0001 至 0013 补丁。构建方式见[源码构建说明](../SOURCE_BUILD.md)。

## 已知现象与执行范围

用户反馈 Bilibili TV／DLNA 投屏在开始约 1 秒后重播开头一次，之后正常；整屏镜像没有该现象。尚无这次过程的指令日志，不能确认发送端是否重复送片或发送进度同步指令。本轮未改变重复送片、Play 和 Seek 策略，也未将该现象列为已修复。

本轮完成源码静态审查、双 ABI Release 构建、对齐及签名，未执行测试、Lint、额外签名验证、截图、模拟器或真机验证，也没有本版覆盖升级的实测结果。0.6.0 的 43 项 JVM 测试、17 组原生检查、模拟器及签名验证结果属于历史版本。逐项范围见[2026-10-28 静态审计记录](../audit-20261028.md)。

默认 4K／60 帧、95% 自适应音频、关闭强制低延迟、高级设置折叠和接收常开保持不变。Miracast、Google Cast 和 DRM 受保护影片仍不在接收范围内。
