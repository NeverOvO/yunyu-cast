# 云屿投屏 0.5.3-preview.1

针对 iPhone 持续镜像中切换相册视频后短暂无声的问题，调整解码前的音频队列，减少接收端不必要的等待。

## 更新内容

- 对已识别的无音频数据标记按 RTP 序号正常消费，不送入解码器，避免把它们当作丢包等待。
- AAC-ELD 音频设置 150ms 缺包等待阈值，超时后跳过连续缺口，继续处理已收到的音频。
- 收到 FLUSH 时清理 RTP 队列，沿用已有的解码器及 PCM 缓冲清理。
- 普通音频、重传、时钟同步和等待超时共用队列排空路径，使已就绪音频及时进入解码。

用户反馈 0.5.2 在切换视频后仍有约 1 至 2 秒无声，声音出现后立即同步。本版针对接收队列中的额外等待进行修复，尚无电视实机复测结果，不能确认该现象已全部消除。没有证据表明每次切换视频都会发送无音频数据标记。

## 安装与附件

已安装 0.5.0 至 0.5.2：在电视首页点“检查更新”→“下载并安装”，按系统提示完成安装。

0.4.1 及以前：下载 `yunyu-cast-0.5.3-preview.1.apk`，通过 U 盘或 ADB 手动覆盖安装。同一发布签名的 0.2.0 至 0.5.2 可保留设置升级；0.1.0 调试签名版本需先卸载。

本版 versionCode 为 `9`，包名为 `com.yunyulai.tvcast`，支持 Android 8.0 及以上 ARM32 / ARM64 电视。附件另含：

- `yunyu-cast-0.5.3-preview.1-source.tar.gz`：对应完整源码，含新增的 UxPlay 0012 补丁。
- `SHA256SUMS.txt`：附件 SHA-256 校验值。
- `THIRD_PARTY_NOTICES.md`：第三方组件与许可说明。

## 构建与使用范围

Release 构建及原发布证书签名已完成。本次没有新增或运行测试、Lint、截图、模拟器或真机复测。现有 PCM 缓冲与 NTP 同步、设备发现、自动接收、应用内更新和默认 4K60 保留。

安卓投屏范围不变：支持兼容 App 通过 DLNA 发送视频，当前未实现 Miracast 或 Google Cast 整屏镜像。详情见[安卓投屏评估](https://github.com/NeverOvO/yunyu-cast/blob/v0.5.3-preview.1/docs/ANDROID_CAST.md)。

源码、使用方式与许可信息见[项目 README](https://github.com/NeverOvO/yunyu-cast/tree/v0.5.3-preview.1)。
