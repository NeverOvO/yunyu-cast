# 云屿投屏 0.5.0-preview.1

新增“检查更新”。以后可以直接在电视上查看新版、下载，并按系统提示确认安装。0.4.1 及以前需要先手动覆盖安装本版一次。

## 更新内容

- 首页和“画面设置”均提供“检查更新”大按钮。应用前台空闲时，也会在距离上次检查至少 12 小时后自动查询。
- 从本仓库公开 GitHub Releases 获取预览版与正式版信息，按语义版本选择有效安装包。无新版时显示“已经是最新版”，网络或服务失败时显示“重试”。
- 用户确认后后台下载，显示百分比；支持稍后安装、取消下载，以及退出重进后恢复进度。
- 下载后检查包名、versionCode、版本名称、最低系统版本、签名及可用的 GitHub SHA-256 摘要，再进入系统安装流程。
- 首次更新引导允许安装来源。安装仍需用户在系统页面确认，投屏期间不弹更新窗口或自动打开安装。
- 更新完成后尝试恢复接收，系统限制后台启动时，重新打开应用即可。

## 安装与附件

下载 `yunyu-cast-0.5.0-preview.1.apk`，在 Android 8.0 及以上 ARM32 / ARM64 电视安装。同一发布签名的 0.2.0 至 0.4.1 可直接覆盖安装并保留设置；0.1.0 或自行构建的调试签名包需先卸载。

本版 versionCode 为 `6`，包名为 `com.yunyulai.tvcast`。附件另含：

- `yunyu-cast-0.5.0-preview.1-source.tar.gz`：对应完整源码。
- `SHA256SUMS.txt`：附件 SHA-256 校验值。
- `THIRD_PARTY_NOTICES.md`：第三方组件与许可说明。

应用内更新操作见[更新指南](https://github.com/NeverOvO/yunyu-cast/blob/v0.5.0-preview.1/docs/UPDATES.md)。GitHub 访问受网络影响，更新失败不影响当前版本投屏。

## 构建状态与使用范围

Release 构建与原发布证书签名已完成。本次没有新增或运行测试、Lint、模拟器或真机检查，电视上的下载、安装权限和安装后恢复仍未实测。0.4.0 的 13 项纯逻辑回归测试属于此前版本，不计入本版检查结果。

现有 AirPlay / DLNA、自动接收、手绘素材和默认 4K60 保留。4K60 为镜像协商目标，实际画质和帧率取决于手机、电视解码能力和网络。DRM 受保护影片、Miracast、Google Cast 和视频平台自有协议仍不支持。

应用代码按 GPL v3 发布，基于 jqssun/android-airplay-server v0.0.36 与 UxPlay。源码、构建及许可信息见[项目 README](https://github.com/NeverOvO/yunyu-cast/tree/v0.5.0-preview.1)。
