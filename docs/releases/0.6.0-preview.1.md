# 云屿投屏 0.6.0-preview.1

本版增加首次自动打开投屏画面的权限引导，并集中修复音频、播放、下载和更新流程中的会话切换与资源清理问题。保留大字引导、接收常开和默认画质，减少日常使用时需要处理的设置。

## 操作变化

- 首次还未允许自动打开画面时，显示“去开启”和“暂不开启”。进入系统应用列表时先选“云屿投屏”，再打开权限。已授权时跳过；跳过或返回未授权后显示之后的开启路径，首次提示不会反复弹出。
- 系统权限页面打不开时保留说明并安全返回。投屏、输入 PIN、其他权限或更新进行时，不叠加首次引导。
- 默认仍为 4K／60 帧、95% 自适应音频，强制低延迟关闭，高级设置折叠，接收保持开启。升级保留有效个性设置。
- 普通 AirPlay TCP 探测不再影响更新忙碌判断、屏幕常亮或画中画。
- Wi-Fi 硬件声明为可选，避免仅使用以太网的电视被设备能力筛选排除。

## 稳定性修复

- 音频会话切换时过滤旧流错误和旧连接断开，修复延迟采样队列满时的数据竞争。
- 分开处理 AirPlay 与 DLNA 音量，避免切换后静音或音量状态相互干扰。
- 播放结束或失败时唤醒原生等待，隔离 DACP 旧会话及迟到命令，限制网络请求资源和总时长，补齐 IPv6 处理。
- 修复影片下载初始化、临时文件和保存完成的竞争；取消或服务销毁时清理资源。
- DLNA 不执行过期连接上的迟到控制。更新恢复要求元数据完整，损坏摘要不降级处理，原有 APK 签名检查继续保留。
- UxPlay 0013 补丁为直播播放列表等待增加 15 秒超时重试，并限制迟到旧播放列表的序列回退。

用户已确认 0.5.4 的 Bilibili 投屏在其索尼电视上正常。这是该用户的实测反馈，不代表全部平台或机型兼容。从 iPhone 屏幕镜像改用 Bilibili 等 App 的 TV／DLNA 投屏前，先在控制中心停止“屏幕镜像”。

## 安装与附件

已安装 0.5.0 至 0.5.4：在电视首页点“检查更新”→“下载并安装”，按系统提示完成安装。

0.4.1 及以前：下载 `yunyu-cast-0.6.0-preview.1.apk`，通过 U 盘或 ADB 手动覆盖安装。同一发布签名的 0.2.0 至 0.5.4 可保留设置升级；0.1.0 调试签名版本需先卸载。

本版 versionCode 为 `11`，包名为 `com.yunyulai.tvcast`，支持 Android 8.0 及以上 ARM32 / ARM64 电视。对应附件：

- `yunyu-cast-0.6.0-preview.1.apk`：电视安装包。
- `yunyu-cast-0.6.0-preview.1-source.tar.gz`：完整源码，包含 UxPlay 0001 至 0013 补丁。
- `SHA256SUMS.txt`：附件 SHA-256 校验值。
- `THIRD_PARTY_NOTICES.md`：第三方组件与许可说明。

## 审计与检查范围

本轮审计覆盖第一方 Kotlin / C++、JNI、UxPlay 补丁及依赖调用边界，不包含逐行审查所有第三方源码，也不作零故障保证。

- 43 项 JVM 回归测试通过，失败、错误和跳过均为 0。
- 17 组原生检查通过：5 组音频缓冲、6 组 RTP 队列、6 组直播播放列表。RTP 测试中的加密与编解码使用桩实现，不计为真实加密或解码测试。
- 完整 lintRelease 通过：0 个错误、70 个警告、1 个提示；没有新增 baseline 或全局 suppress，剩余警告和检查边界在审计记录中说明。
- ARM32 / ARM64 Release 构建完成，原发布证书签名及 APK v2 / v3 验证通过，证书 SHA-256 与 0.5.4 一致。
- Android 35 模拟器已检查 960×540 逻辑横屏、1.5 倍字体、遥控操作、拒绝后重启不重复提示、未授权返回说明及系统授权后状态更新。预先授权时跳过首次引导，返回退出后前台接收服务仍运行。
- 隔离模拟器使用最终 APK 从 0.5.4 覆盖升级成功，原 1080p／30 帧设置保留；清除数据后的首次启动显示默认 4K／60 帧。

独立 Android 35 平板模拟器检查不等同于索尼电视或真实 AirPlay / DLNA 投屏。逐项结果见[0.6.0 代码审计记录](https://github.com/NeverOvO/yunyu-cast/blob/v0.6.0-preview.1/docs/audit-20261027.md)。

安卓投屏范围不变：兼容 App 可通过 DLNA 发送视频，当前未实现 Miracast 或 Google Cast 整屏镜像，未完成安卓手机机型实测。详情见[安卓投屏评估](https://github.com/NeverOvO/yunyu-cast/blob/v0.6.0-preview.1/docs/ANDROID_CAST.md)。

源码、使用方式与许可信息见[项目 README](https://github.com/NeverOvO/yunyu-cast/tree/v0.6.0-preview.1)。
