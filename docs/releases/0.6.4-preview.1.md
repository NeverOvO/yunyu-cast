# 云屿投屏 0.6.4-preview.1

本版补齐 AirPlay 异常数据检查和连接资源释放，修正系统媒体按键的控制状态，并在退出界面后继续保存后台日志。已安装 0.5.0 至 0.6.3 的电视可在首页点“检查更新”，再点“下载并安装”。

## 本版改动

- 镜像视频先检查数据长度和编码参数，再交给解码器；限制单个压缩包大小，内存不足时结束当前镜像处理，不直接退出整个应用。
- 释放断线套接字、未处理完的视频缓冲和周期状态报告，处理长时间投屏或反复连接可能累积资源的问题。
- 系统或蓝牙媒体按键与应用内控件使用同一套播放入口；暂停、快进、快退和手动定位会取消启动回零例外。
- 后台接收日志由进程统一保存，界面退出或重建期间仍可记录连接与错误；日志条数、单条长度及批量写入限制继续生效。

用户已反馈 0.6.3 可用，本版保留其 Bilibili 起播兼容、日志翻页、分层返回与持续接收方式。默认画质和音频配置不变。启动窗口内首次手动回零仍可能与 App 初始化对齐指令混淆，第二次回零正常执行，详见 [0.6.3 说明](https://github.com/NeverOvO/yunyu-cast/blob/main/docs/releases/0.6.3-preview.1.md)。

## 版本与安装

版本为 `0.6.4-preview.1`，versionCode 为 `15`，包名为 `com.yunyulai.tvcast`。沿用原发布证书，可覆盖安装并保留设置；0.4.1 及以前通过 U 盘或 ADB 更新。

本版附件包含双 ABI APK、完整源码包、SHA256SUMS.txt 和第三方许可说明。完整源码使用固定原生依赖及 UxPlay 0001 至 0016 补丁，包含 OpenSSL 3.4.4 原始源码包；签名私钥及本机配置不随附件分发。

## 执行范围

ARM32 / ARM64 Release 构建、R8 处理、16 KiB 对齐与原发布证书签名已完成，相关命令退出码均为 0。

源码已完成静态审计，详见[审计记录](https://github.com/NeverOvO/yunyu-cast/blob/main/docs/audit-0.6.3-20261028.md)。本轮未运行测试、Lint、额外签名验证、模拟器或电视实测；用户对原 0.6.3 的确认不代表本版新增修补已通过设备回归。
