# 云屿投屏 0.5.4-preview.1

修复 AirPlay 设备探测连接误占 DLNA 播放会话的问题，并增加投屏指令和播放失败原因记录，处理视频 App 已选中设备但影片未开始播放的情况。

## 更新内容

- 普通 AirPlay TCP 探测连接不再计为正在播放的媒体会话，避免因此拒绝或中断 DLNA。
- 协议间播放归属按实际媒体回调处理，设备探测不再改变 DLNA 播放状态或唤起首页。
- 调整媒体会话生命周期，避免镜像内切换影片时反复打开界面，以及过期媒体回调打断 DLNA。
- 增加脱敏的 DLNA 指令、UPnP 和 HTTP 错误日志。
- 播放器错误保留 HTTP 状态、域名解析、超时等原因分类，移除一律猜测登录授权的文案。

本版针对 Bilibili 选中云屿投屏后时长显示 00:00、电视停在引导页的反馈调整代码。用户日志已有 DLNA 收到影片并开始播放的记录，但本版尚未完成电视首次连接复测，不能确认覆盖全部 Bilibili 投屏情况，也不代表官方认证。

从 iPhone 屏幕镜像改用 Bilibili 等视频 App 的 TV／DLNA 投屏前，先在控制中心停止“屏幕镜像”。应用不会强制打断正在播放的真实 AirPlay 媒体会话。

## 安装与附件

已安装 0.5.0 至 0.5.3：在电视首页点“检查更新”→“下载并安装”，按系统提示完成安装。

0.4.1 及以前：下载 `yunyu-cast-0.5.4-preview.1.apk`，通过 U 盘或 ADB 手动覆盖安装。同一发布签名的 0.2.0 至 0.5.3 可保留设置升级；0.1.0 调试签名版本需先卸载。

本版 versionCode 为 `10`，包名为 `com.yunyulai.tvcast`，支持 Android 8.0 及以上 ARM32 / ARM64 电视。附件另含：

- `yunyu-cast-0.5.4-preview.1-source.tar.gz`：对应完整源码，包含 UxPlay 0001 至 0012 补丁。
- `SHA256SUMS.txt`：附件 SHA-256 校验值。
- `THIRD_PARTY_NOTICES.md`：第三方组件与许可说明。

## 构建与使用范围

Release 构建及原发布证书签名已完成，安装包为 `yunyu-cast-0.5.4-preview.1.apk`。本次没有新增或运行测试、Lint、截图、模拟器或真机复测。现有镜像音频与 NTP 同步、自动接收、应用内更新和默认 4K60 保留。

安卓投屏范围不变：支持兼容 App 通过 DLNA 发送视频，当前未实现 Miracast 或 Google Cast 整屏镜像。详情见[安卓投屏评估](https://github.com/NeverOvO/yunyu-cast/blob/v0.5.4-preview.1/docs/ANDROID_CAST.md)。

源码、使用方式与许可信息见[项目 README](https://github.com/NeverOvO/yunyu-cast/tree/v0.5.4-preview.1)。
