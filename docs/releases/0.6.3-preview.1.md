# 云屿投屏 0.6.3-preview.1

本版处理 Bilibili TV／DLNA 起播后回到开头的问题，增加日志翻页，并调整遥控返回路径。用户提供的 0.6.2 日志已记录到：播放器正常起播后收到 DLNA Seek(0)，播放进度由 1630 ms 回到 0 ms，随后重新缓冲与显示首帧。这次重播由该跳转指令触发，没有发生播放器重建。

## 投屏起播

新增一次性的 DLNA 启动回零兼容处理：新影片从 0 开始，起播指令后不超过 8 秒、实际进度在 0–3 秒内，且仍在播放、没有缓冲或其他跳转／暂停操作时，将第一个回零按初始位置对齐处理，继续当前播放。日志记录“启动重复回零已略过”及当时进度。

任何一次 Seek 都会消耗这次机会。非零跳转、播放前设置起点、暂停后继续、遥控快进快退与拖动进度均保留原有操作；第二次回零照常执行。切换影片重新计算，停止、结束及切换协议时清理状态。屏幕镜像不使用这条规则。

DLNA 指令不携带“自动初始化／用户点击”的区分信息，因此该处理是针对已观察行为的兼容规则。在上述狭窄范围内首次手动回零也可能被略过，再次操作即会执行；尚无本版电视实测结果。

## 日志与遥控

- 日志底部固定显示“上一页”“下一页”“查看最新”，按钮使用大字和与按钮一致的焦点圆角。
- 每次翻页约移动一屏并保留部分重叠，长日志换行仍可连续阅读。支持遥控方向键以及键盘 Page Up／Page Down。
- 翻看旧日志时保留当前快照，新记录不会把页面拉到底部或挤掉正在看的内容；点“查看最新”恢复跟随。
- 显示当前可见记录范围和浏览状态；窄窗口时按钮换行。
- 日志、画面设置按返回回到投屏首页；投屏时按返回结束本次投屏并回首页，后台接收保持开启。
- 弹窗仍先关闭；只有在空闲首页再次按返回才退出到电视桌面。播放器画面里的返回按钮也回首页。
