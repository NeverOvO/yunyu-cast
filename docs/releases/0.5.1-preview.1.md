# 云屿投屏 0.5.1-preview.1

修复按钮与遥控器选中框的圆角不一致问题。选中框现在沿按钮自身轮廓显示，胶囊按钮两侧不再使用另一套圆角。

## 更新内容

- 首页、连接帮助、更新弹窗和返回首页按钮共用按钮与焦点框形状。
- 设置选项的焦点框采用控件自身形状，图标按钮使用圆形；滑块与整行设置保留原有形状。
- 按钮尺寸、字号、配色及操作流程保持不变。

## 安装

已安装 0.5.0：在电视首页点“检查更新”→“下载并安装”，按系统提示完成安装。

0.4.1 及以前：下载 `yunyu-cast-0.5.1-preview.1.apk`，通过 U 盘或 ADB 手动覆盖安装。同一发布签名的 0.2.0 至 0.5.0 可保留设置升级；0.1.0 调试签名版本需先卸载。

本版 versionCode 为 `7`，包名为 `com.yunyulai.tvcast`，支持 Android 8.0 及以上 ARM32 / ARM64 电视。附件包含 APK、`yunyu-cast-0.5.1-preview.1-source.tar.gz` 完整源码、`SHA256SUMS.txt` 和 `THIRD_PARTY_NOTICES.md`。

## 构建范围

Release 构建及原发布证书签名已完成。本次没有新增或运行测试、Lint、截图、模拟器或真机复测。电视上的圆角显示和完整升级流程尚未实测。现有 AirPlay / DLNA、自动接收、应用内更新和手绘素材保留。

源码、使用方式与许可信息见[项目 README](https://github.com/NeverOvO/yunyu-cast/tree/v0.5.1-preview.1)。
