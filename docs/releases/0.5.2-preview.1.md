# 云屿投屏 0.5.2-preview.1

针对 iPhone 持续屏幕镜像中切换相册视频时的声音延后、随后短暂卡顿或追赶现象，修复音频启动和缓冲处理，并补充安卓手机投屏说明。

## 更新内容

- 根据电视实际提供的解码器列表选择 AAC 解码器，避免先尝试不存在的进程内解码器而阻塞音频收包。
- 音频收到 FLUSH 时清理旧解码输出、PCM 缓冲、播放时间线和自适应延迟历史。
- 音频格式变化或较长空闲后恢复时重新建立缓冲状态，减少旧延迟历史影响下一段视频。
- 安卓视频 App 和相册视频可通过兼容的 DLNA 发送方式投屏；当前未实现 Miracast 或 Google Cast 整屏镜像，详情见[安卓投屏评估](https://github.com/NeverOvO/yunyu-cast/blob/v0.5.2-preview.1/docs/ANDROID_CAST.md)。

这些改动处理了代码中已发现的音频启动和缓冲问题。本次没有现场日志复现或电视复测，尚不能确认用户描述的全部音画不同步现象都已消除。

## 安装与附件

已安装 0.5.0、0.5.1：在电视首页点“检查更新”→“下载并安装”，按系统提示完成安装。

0.4.1 及以前：下载 `yunyu-cast-0.5.2-preview.1.apk`，通过 U 盘或 ADB 手动覆盖安装。同一发布签名的 0.2.0 至 0.5.1 可保留设置升级；0.1.0 调试签名版本需先卸载。

本版 versionCode 为 `8`，包名为 `com.yunyulai.tvcast`，支持 Android 8.0 及以上 ARM32 / ARM64 电视。附件另含：

- `yunyu-cast-0.5.2-preview.1-source.tar.gz`：对应完整源码。
- `SHA256SUMS.txt`：附件 SHA-256 校验值。
- `THIRD_PARTY_NOTICES.md`：第三方组件与许可说明。

Release 构建及原发布证书签名已完成。本次没有新增或运行测试、Lint、截图、模拟器或真机复测，也未进行安卓机型实测。0.4.0 的测试和审计属于历史记录，不计入本版结果。现有设备发现、自动接收、应用内更新、手绘素材和默认 4K60 保留。
