# 电视检查更新页面

沿用现有深蓝底与手绘云朵电视，不增加新的视觉主题。首页第三个大按钮为“检查更新”，根据状态显示“发现新版本”“更新下载中”或“安装更新”；设置顶部提供同一入口。

## 视觉与布局

- 背景 #101E35，弹窗 #1B304D，主按钮 #A7CFFF，主按钮文字 #102640。
- 正文 #FFFFFF，辅助文字 #DCEBFF；错误提示沿用主题柔红色。
- 系统中文无衬线，标题 28sp、正文和操作 20sp；主要操作最小高度 56dp。
- 弹窗最大宽度 720dp，内容左对齐；0.6.1 以宿主窗口扣除系统安全区域后的高度为上限，并保留上下外边距。
- 标题、版本、说明和进度位于独立滚动区，底部操作按钮保持可达。正文超出可用高度时可获取遥控焦点，按上下键滚动，到达边界后继续移动焦点。
- 手绘图标只放在标题旁，避免装饰干扰更新动作。

```text
云朵电视  发现新版本
          当前版本 / 新版本

精简更新说明
下载进度与状态（需要时显示）

[下载并安装] [以后再说]
```

下载中主要操作改为“稍后安装”，仅关闭弹窗并继续后台下载；另有“取消下载”。安装权限页面返回后由宿主继续处理。已是最新版时用“知道了”结束，失败时用“重试”。安装前说明系统还会要求确认，安装会暂时退出投屏。

所有正文明确设定为白色或浅色，不依赖父布局默认文字颜色。只在用户打开入口后显示弹窗，不主动覆盖正在播放的画面。

安装包准备使用进程内共享互斥锁，多个更新模型实例不会同时清理或写入同一安装临时文件。

0.6.1 已完成双 ABI Release 构建、对齐及原发布证书签名，安装包入口见[本版发布页](https://github.com/NeverOvO/yunyu-cast/releases/tag/v0.6.1-preview.1)。本轮未执行测试、Lint、额外签名验证、截图、页面操作、模拟器或真机验证。
