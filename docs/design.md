# 云屿投屏电视界面与手绘素材

## 家庭使用方式

首页显示设备名称、接收状态、画质和两种手机投屏入口。主要操作为“画面设置”“连接帮助”和“检查更新”。0.6.1 在右下角增加已安装应用的版本号，直接读取系统包信息，使用辅助文字颜色，不增加遥控焦点。应用自动接收，手机停止投屏后继续等待下一次连接。遥控器返回结束本次投屏并回到软件首页，接收服务继续运行；日志和设置返回首页，空闲首页再次返回才退出到桌面，弹窗先由返回键关闭。

技术信息、AirPlay / DLNA 状态、电视 IP、刷新发现和日志放在连接帮助中。设置保留 1080p、2K、4K 与 30 / 60 帧，默认请求 4K60；更多技术设置折叠。自动打开画面的系统权限使用一次性开启入口。

## 电视适配

横屏首页使用左右内容区，操作区位于下方。左右保留 36–48dp，上下保留 24–32dp；使用系统安全区域。低高度和大字号时允许内容滚动，窄屏改为纵向布局，不以缩小全部文字来挤入页面。字体使用 Android 系统无衬线和中文字体，标题 32–38sp，主要操作 20sp。遥控焦点使用清晰边框。按钮与焦点框共用同一胶囊形状，覆盖首页、连接帮助、更新弹窗和返回首页操作；设置选项与图标按钮分别沿控件原有圆角、圆形绘制。滑块和整行设置保留各自形状。

```text
云朵电视 / 云屿投屏           投手机画面
等待手机投屏                 控制中心 › 屏幕镜像
同一 Wi-Fi 与设备选择提示     投视频、电影
画质                         视频 App › TV / 投屏

[画面设置]  [连接帮助]  [检查更新]
手机可停止投屏；投屏中返回回首页，后台持续接收
```

## 0.6.1 交互与高度约束

首页增加版本行后，固定高度横屏布局要求可用高度至少为 `520dp × fontScale`；低于该范围时沿用内容滚动。版本号随底部内容排布，保持电视安全边距。

更新弹窗和首次自动打开画面权限弹窗以宿主窗口的安全高度为上限。正文独立滚动，操作按钮留在底部；正文有溢出内容时可获取遥控焦点，用上下键滚动，到达边界后继续移动焦点。

镜像全屏控件隐藏后，方向键和确定键可以唤醒，焦点进入“退出全屏”按钮。唤醒按键的重复和抬起事件不会触发按钮。点击“退出全屏”返回应用内预览，实体返回键仍结束会话并退出界面。

音乐快进、快退按钮支持遥控按住操作；抬起、控件失焦、窗口失焦或控件销毁时结束扫描。PIN 弹窗由 Activity 统一显示，直接视频播放不再绕过它，返回和确认仅关闭弹窗；画中画期间保留 PIN 状态，返回应用后显示。

本节记录 0.6.1 的界面与交互设计。本版已完成 Release 构建和签名，没有本轮截图、界面操作或电视实机结果。

## 视觉素材

2026-10-25 更换为手绘云朵小电视：暖白云朵、轻微粉色腮红、浅蓝电视和深蓝粗轮廓，使用水粉和彩铅轻纹理。桌面图标与首页标记共用同一图形，电视桌面横幅使用同一形象与大字应用名。

应用保留深海蓝 #101E35 背景、层次蓝 #1B304D、雾蓝 #A7CFFF 焦点和白色 #F4F8FF 正文。插画仅作为品牌标记，不影响文字对比度。

- 素材方案：`design/handdrawn/outline.md`。
- 完整提示词：`design/handdrawn/prompts/`。
- 图标原图：`design/handdrawn/icon-master.png`。

## 0.6.3 日志阅读与返回路径

延续深海蓝 #101E35、面板蓝 #14243C、层次蓝 #1B304D、雾蓝焦点 #A7CFFF、正文白 #F4F8FF。页面只保留一个日志阅读区和固定底部操作区，不为每条日志增加卡片。系统无衬线用于标题和 20sp 按钮；15sp 等宽日志左对齐、长行换行。按钮最小高度 56dp，按钮与焦点框共用胶囊形状，窄窗口自动换行。

```text
[返回投屏首页]   后台持续接收
日志                              分享  清空
时间  控制动作与播放器记录
时间  控制动作与播放器记录
时间  控制动作与播放器记录
第 …–… 条，共 … 条 · 浏览状态
[上一页]  [下一页]  [查看最新]
```

翻页按可用阅读区高度移动 85%，保留上下文。浏览期间冻结记录快照，新的日志以及有界缓冲淘汰旧记录都不改变当前内容；查看最新恢复自动跟随。按钮到达首尾仍保留焦点，避免焦点突然落到清空操作。遥控返回从日志／设置回首页，从投屏结束当前会话并回首页，在空闲首页再按才退出。上述布局遵循既有电视配色和安全边距，本轮未进行截图或设备验证。
